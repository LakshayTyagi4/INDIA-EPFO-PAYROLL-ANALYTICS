# Wireframes

Low-fidelity plan for the report's 5 pages, sketched out **before** building them in
Power BI — [`report_wireframe.svg`](report_wireframe.svg).

Pages planned:
1. **Overview** — headline KPI cards, Smart Narrative auto-summary, mini trend sparkline
2. **Trend** — main Net Payroll line chart with a Rolling 3-Month Average overlay,
   Fiscal Year / Age Band slicers, MoM/YoY KPI cards
3. **Age-Band Breakdown** — Decomposition Tree (Total → AgeBand → Month), a
   clustered bar chart by age band, Key Influencers
4. **COVID-19 Impact** — a dedicated insight page: Pre-COVID vs COVID-era average
   monthly net payroll, a trend chart with the Mar–Aug 2020 window highlighted, and
   a text callout
5. **Methodology** — data source, refresh cadence, known limitations, model summary

This is a plan to build from, not a screenshot of the finished report — if the
actual build ends up diverging from it (a page gets split, merged, or dropped),
update this file so it stays a reliable record of intent rather than going stale.
