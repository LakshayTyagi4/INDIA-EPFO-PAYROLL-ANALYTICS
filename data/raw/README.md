# Raw data

Monthly "Provisional Estimate of Payroll" PDF reports, downloaded as-is from
https://www.epfo.gov.in/data-hub/

Naming convention: `YYYY-MM.pdf` (e.g. `2024-01.pdf` for the January 2024 release).

These are committed to the repo so the project is fully reproducible from GitHub alone —
each file is small (a few hundred KB to ~3 MB), so total repo size stays well within normal git limits.
